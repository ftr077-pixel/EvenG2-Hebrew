# סקירה כללית

ברוכים הבאים לתיעוד המפתחים של **Even Hub** — פלטפורמת הפיתוח לאפליקציות משקפיים חכמות Even G2.

## מהו Even Hub?

Even Hub הוא חנות אפליקציות ופלטפורמת פיתוח המיועדת באופן בלעדי למשקפיים החכמים G2. הפלטפורמה מאפשרת קשר ישיר בין יוצרים חיצוניים למשתמשי G2, ומהפכת את המכשיר לאקוסיסטם פתוח ורב-תכליתי.

ה-SDK של Even Hub מספק ממשקי API ברמה גבוהה שמטפלים בפרטי החומרה והמערכת עבורך, כך שתוכל להתמקד בהתנהגות האפליקציה שלך.

## מה ניתן לבנות?

אפליקציית G2 היא אפליקציית Web רגילה — ללא מסגרת מיוחדת או עטיפה נדרשת. רק HTML, TypeScript וה-SDK של Even Hub לתקשורת עם המשקפיים.

הזדמנויות הפיתוח כוללות:

- **יישומי תצוגה (Widgets)** — הצגת מידע שימושי ישירות בשדה הראייה של המשתמש
- **יישומי AI** — שילוב מודלים של בינה מלאכותית עם הקלט הקולי של המשקפיים
- **ניגוב נתוני IMU** — גישה לנתוני תנועה מהחיישנים המובנים
- **ממשקי רשימות וטקסט** — יצירת ממשקי ניווט אינטואיטיביים

### המתאים ביותר לתצוגת HUD

חשוב לתכנן לתצוגה "במבט אחד" (glanceable). הדוגמאות הטובות ביותר:

- **ניווט** — הצגת הפנייה הבאה בלבד
- **תרגום** — הצגת ביטוי בודד
- **CRM** — הצגת הפעולה הבאה הטובה ביותר בלבד

לוח מחוונים מרובה שדות אינו מתאים לתצוגת ראש (HUD). פחות הוא יותר.


## התחלה מהירה

### 1. אתחול הגשר (Bridge)

```typescript
import { waitForEvenAppBridge } from '@evenrealities/even_hub_sdk';

const bridge = await waitForEvenAppBridge();
```

### 2. קבלת מידע על המשתמש והמכשיר

```typescript
const user = await bridge.getUserInfo();
const device = await bridge.getDeviceInfo();
```

### 3. יצירת ממשק למשקפיים

> **חשוב:** יש לקרוא ל-`createStartUpPageContainer` לפני כל פעולת UI אחרת.

```typescript
const result = await bridge.createStartUpPageContainer({
  containerTotalNum: 2,
  listObject: [listContainer],
  textObject: [textContainer],
});

if (result === 0) {
  console.log('ממשק נוצר בהצלחה');
}
```

### 4. האזנה לאירועים

```typescript
bridge.onEvenHubEvent((event) => {
  if (event.listEvent) {
    // טיפול בבחירה מרשימה
  } else if (event.sysEvent?.imuData) {
    const { x, y, z } = event.sysEvent.imuData;
    // טיפול בנתוני תנועה
  } else if (event.audioEvent) {
    // טיפול בזרם שמע PCM
  }
});
```

## מערכת הקואורדינטות

ממשק המשקפיים משתמש בקואורדינטות עם מקור בפינה **הימנית העליונה (0,0)**:

- ציר X — משמאל לימין
- ציר Y — מלמעלה למטה
- רזולוציה מקסימלית לתמונות: **288×144 פיקסלים**

## מגבלות ידועות

| פרמטר | מגבלה |
|-------|-------|
| מכולות (containers) לדף | מקסימום 12 |
| פריטים ברשימה | מקסימום 20 |
| תווים במכולת טקסט | מקסימום 2,000 |
| מכולות טקסט לדף | מקסימום 8 |
| לכידת אירועים | מכולה אחת בלבד |

לפיתוח וניפוי שגיאות ללא משקפיים פיזיים, ניתן להשתמש בסימולטור:

```bash
npm install
```
